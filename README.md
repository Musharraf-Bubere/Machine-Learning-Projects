## 🐉 1. Dragon Real Estate Price Prediction

A complete machine learning regression project that predicts house prices based on multiple features from the California Housing dataset.

### 🔍 Highlights
- Data cleaning & preprocessing  
- Exploratory data analysis (EDA)  
- Feature engineering  
- Multiple regression models  
- Model comparison  
- Best model: **Random Forest Regression**  
- Saved trained model using Joblib  

### 📂 Project Folder  
`01_Dragon_Real_Estate_Price_Prediction_Model/`

### 🚀 How to Run
```bash
cd 01_Dragon_Real_Estate_Price_Prediction_Model
pip install -r requirements.txt
jupyter notebook Dragon_Real_Estate.ipynb
```
